# José David Gómez Chamorro

Portafolio profesional de experiencia en operaciones industriales, mantenimiento, análisis de datos y desarrollo de software.

**Sitio:** [joseggch15.github.io/Interview](https://joseggch15.github.io/Interview/)

La presentación reúne la trayectoria laboral, la formación académica y cinco proyectos: Fleet Maintenance, Intake vs Delivery, Overfill SFL Spy, Sweeper & Mop y HMI Tank.

## Privacidad y demostraciones

Las capturas muestran las cinco aplicaciones originales ejecutadas en entornos de demostración con datos 100% sintéticos. Los grupos, equipos, identificadores, usuarios, fechas, volúmenes y lecturas son ficticios. No se publican datos operativos, código empresarial ni el CV original. El empleador actual permanece confidencial. Los ejemplos interactivos desplegables son recreaciones simplificadas para explicar la lógica de cada proyecto.

Los programas identificados como en curso reflejan el estado consignado en el CV utilizado para preparar el portafolio. Los ejemplos técnicos no representan ahorros, productividad o resultados operativos reales.

## Uso

Abre el sitio y pulsa **Modo presentación** para recorrer sus 17 secciones. Avanza con los botones o las flechas del teclado y sal con Escape. Puedes cambiar entre Español/English y tema claro/oscuro; las preferencias se conservan en el navegador. Selecciona una captura para ampliarla o despliega el ejemplo interactivo para explorar datos ficticios.

El recorrido visual inicial usa capas de imágenes, transiciones y movimiento suave ligados al desplazamiento. Puedes pausar el movimiento; también respeta la preferencia del sistema de reducir animaciones. En modo presentación utiliza los tres botones de escenas.

Las imágenes de industria, ingeniería naval y datos son conceptos generados, etiquetados en la página. No representan instalaciones reales. Las capturas del software son imágenes de las aplicaciones funcionando y no son imágenes generadas.

La sección GitHub complementa el CV con los repositorios públicos [hmisilos](https://github.com/joseggch15/hmisilos), [ReactCoderHouseProyectoFinal](https://github.com/joseggch15/ReactCoderHouseProyectoFinal) y [MyPortafolioWithAstro](https://github.com/joseggch15/MyPortafolioWithAstro), según sus README y archivos de configuración.

La idea de narrativa visual con un escenario fijo y transiciones al desplazarse toma como referencia [mcp-higgsfield-landing](https://github.com/midudev/mcp-higgsfield-landing). La implementación y los recursos visuales de este portafolio son propios; no se utilizan los recursos del restaurante.

La carpeta `materiales/` contiene datos de demostración y una presentación de apoyo en PowerPoint orientada a la entrevista con Diametral.

## Publicación

Sitio estático sin dependencias externas ni proceso de compilación. GitHub Pages publica desde la raíz de la rama `main`. El archivo `.nojekyll` permite servir los archivos directamente.

Los archivos HTML, CSS y JavaScript también pueden abrirse localmente conservando esta estructura.
