# Recursos visuales / Visual assets

Los archivos `company-*.png` son los logos proporcionados por el titular para acompañar las experiencias profesionales. Se conservan sus colores y archivos originales. PLG identifica al empleador del cargo actual; Newmont identifica al cliente de los servicios descritos.

The `company-*.png` files are the logos supplied by the portfolio owner. PLG identifies the current employer; Newmont identifies the client associated with the described services.

Las capturas fleet, intake, overfill, sweeper y hmi muestran las aplicaciones originales ejecutadas en entornos de demostración con datos generados desde cero. Nombres, grupos, equipos, fechas, cantidades y lecturas son ficticios.

industrial.png, naval.png y data.png son imágenes conceptuales generadas para ilustrar la trayectoria profesional. No representan instalaciones, proyectos ni interfaces reales.

Software screenshots use 100% synthetic operational data. The three cinematic images are generated concepts, separate from actual application screenshots.
