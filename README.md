# José David Gómez Chamorro

Portafolio profesional de experiencia en operaciones industriales, mantenimiento, análisis de datos y desarrollo de software.

**Sitio:** [joseggch15.github.io/Interview](https://joseggch15.github.io/Interview/)

La presentación reúne la trayectoria laboral, la formación académica y cinco proyectos: Fleet Maintenance, Intake vs Delivery, Overfill SFL Spy, Sweeper & Mop y HMI Tank.

## Privacidad y demostraciones

Las cinco demostraciones interactivas son recreaciones simplificadas con datos 100% sintéticos. Los grupos, equipos, identificadores, usuarios, fechas, volúmenes y lecturas son ficticios. No se publican bases, capturas, código empresarial ni el CV original. El empleador actual permanece confidencial.

Los programas identificados como en curso reflejan el estado consignado en el CV utilizado para preparar el portafolio. Los ejemplos técnicos no representan ahorros, productividad o resultados operativos reales.

## Uso

Abre el sitio y pulsa **Modo presentación** para recorrer sus 15 secciones. Avanza con los botones o las flechas del teclado y sal con Escape. Los controles de cada demostración permiten explorar los datos ficticios.

La carpeta `materiales/` contiene datos de demostración y una presentación de apoyo en PowerPoint orientada a la entrevista con Diametral.

## Publicación

Sitio estático sin dependencias externas ni proceso de compilación. GitHub Pages publica desde la raíz de la rama `main`. El archivo `.nojekyll` permite servir los archivos directamente.

Los archivos HTML, CSS y JavaScript también pueden abrirse localmente conservando esta estructura.
