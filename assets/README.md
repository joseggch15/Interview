# Recursos visuales / Visual assets

Los archivos `company-*.png` son los logos proporcionados por el titular para acompañar las experiencias profesionales. Se conservan sus colores y archivos originales. PLG identifica al empleador del cargo actual; Newmont identifica al cliente de los servicios descritos.

The `company-*.png` files are the logos supplied by the portfolio owner. PLG identifies the current employer; Newmont identifies the client associated with the described services.

Las capturas fleet, intake, overfill, sweeper y hmi muestran las aplicaciones originales ejecutadas en entornos de demostración con datos generados desde cero. Nombres, grupos, equipos, fechas, cantidades y lecturas son ficticios.

industrial.png, naval.png y data.png son imágenes conceptuales generadas para ilustrar la trayectoria profesional. No representan instalaciones, proyectos ni interfaces reales.

The five operational-analysis software demos use 100% synthetic data. The three cinematic images are generated concepts, separate from actual application screenshots.

Los doce archivos `history-*` son imágenes históricas reales compartidas por el titular: cuatro fotografías de interfaces COTECMAR y ocho imágenes extraídas directamente de su portafolio. Se conservan los originales sin retoques, recortes ni generación. Las imágenes de Biofilm, STIP y Taghleef ilustran experiencia industrial; las de COTECMAR acompañan la participación frontend dentro de un equipo. Estos recursos se distinguen de las cinco demostraciones de análisis operativo con datos sintéticos.

The twelve `history-*` files are real historical images supplied by the portfolio owner: four photographs of COTECMAR interfaces and eight images extracted directly from the historical portfolio. Originals are preserved without retouching, cropping or generation. Biofilm, STIP and Taghleef illustrate industrial experience; COTECMAR accompanies frontend participation within a team. These assets are separate from the five operational-analysis demos using synthetic data.
